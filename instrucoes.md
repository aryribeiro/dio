DESCRIÇÃO

Desenvolva uma aplicação Fullstack para uma Carteira de Investimentos utilizando Rust. Ao longo do projeto, você vai criar uma API com Axum, armazenar dados no PostgreSQL, implementar autenticação de usuários e construir páginas HTML com Askama. O desafio conecta Back-End, banco de dados, segurança e interface em uma única aplicação. Ao final, você poderá evoluir o projeto com novas funcionalidades para acompanhar ativos e organizar uma carteira de investimentos.



Entendendo o Desafio

Agora é a sua hora de praticar, aprender fazendo e evoluir um projeto completo com Rust! Neste desafio, você vai trabalhar em uma aplicação Fullstack para uma Carteira De Investimentos. O projeto une uma API, banco de dados, autenticação e páginas web em uma única aplicação. Antes de começar, acesse o repositório do projeto:

Repositório Base:
https://github.com/digitalinnovationone/rust-fullstack-carteira-investimentos

Nas aulas, o expert desenvolve os principais passos junto com você. Use o código como referência, revise os conteúdos sempre que precisar e depois personalize sua entrega.
O Que Você Vai Construir

O projeto apresenta a base de uma aplicação para cadastrar e acompanhar ativos de investimento. Durante o desenvolvimento, você vai praticar:

    Criar uma aplicação web com Rust e Axum;
    Organizar rotas e responsabilidades do projeto;
    Salvar dados no PostgreSQL com SQLx;
    Criar, listar e atualizar ativos;
    Cadastrar e autenticar pessoas usuárias;
    Usar cookies e JWT para manter o acesso autenticado;
    Criar páginas HTML com Askama;
    Executar o banco de dados com Docker;
    Testar as principais operações da aplicação.

Como Fazer

Primeiro, acompanhe as aulas e execute o projeto apresentado pelo expert. Isso vai ajudar você a entender como cada parte da aplicação funciona.

Depois, evolua o projeto de acordo com seu conhecimento e suas ideias. Você pode, por exemplo:

    Melhorar o dashboard da aplicação;
    Criar formulários para cadastrar e editar ativos;
    Adicionar novos dados aos investimentos;
    Calcular o valor total da carteira;
    Melhorar as validações e mensagens de erro;
    Criar novos testes;
    Melhorar a documentação do projeto.

Se você ainda está começando, tudo bem. Uma melhoria simples, funcionando e bem explicada já representa uma ótima evolução.
